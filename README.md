# 🟡 Pac-Man Python Game

A simple Pac-Man style arcade game built using Python.

## 🎮 Features

- Control Pac-Man using the arrow keys
- Collect dots to increase your score
- Avoid the ghosts
- Classic maze-style gameplay
- Built using Python Turtle graphics

## 🛠️ Technologies Used

- Python
- Turtle
- Freegames
